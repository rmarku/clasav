# Milestone 1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Sails app with a Go single-binary skeleton: layered config, SQLite + Postgres storage with goose migrations, local accounts with server-side sessions, the content pack (converted from the legacy fixtures) with validation, and the portal's login/register/account pages.

**Architecture:** Hexagonal. `internal/domain` (pure rules) ← `internal/app` (use cases) ← `internal/ports` (interfaces) ← `internal/adapters/*` (SQLite, Postgres, memory, bcrypt, content, HTTP). Only `cmd/clasav` wires adapters together. The portal is server-rendered templ + HTMX. Content lives in `content/`, is embedded into the binary, and can be overridden file by file with `--content-dir`.

**Tech Stack:** Go 1.26 (module directive), koanf v2 (YAML/env/flags), pflag, goose v3 (Provider API), modernc.org/sqlite (pure Go), pgx v5 stdlib, testcontainers-go (Postgres tests), golang.org/x/crypto/bcrypt, golang.org/x/term, templ v0.3.1020, htmx 2.0.11, Pico CSS 2.1.1, golangci-lint v2.

**Spec:** `docs/superpowers/specs/2026-09-24-clasav-go-migration-design.md` (milestone 1 = §11 item 1; also §2, §3, §4, §6.1, §6.2 account pages, §7, §8, §9).

## Global Constraints

- Module path `github.com/rmarku/clasav`; `go.mod` declares `go 1.26`.
- `CGO_ENABLED=0 go build ./cmd/clasav` must succeed (pure-Go SQLite driver only).
- `internal/domain` imports only the standard library. `internal/ports` imports stdlib + `domain`. `internal/app` (non-test files) imports stdlib + `domain` + `ports`. Only `cmd/clasav` imports `internal/adapters/...` for wiring (adapters may import `app`, `ports`, `domain`). Enforced by depguard.
- English identifiers in code, schema and JSON keys; Spanish (rioplatense "vos") user-facing text.
- Domain validation returns message **codes** (`required`, `invalid`, `too_short`, `too_long`, `taken`, `mismatch`, `wrong`); only the views translate them.
- SQLite and Postgres migrations share version numbers (`00001_identity.sql` in both).
- Timestamps are stored in UTC with microsecond precision on both engines.
- Configuration layering: struct defaults < YAML file < `CLASAV_*` env (`__` = nesting) < flags explicitly set on the command line. Unknown keys are an error.
- Secrets are never committed. The session token is random, opaque, and stored only as a SHA-256 hash.
- Push to `origin` (Forgejo) only; GitHub is a push mirror.
- Commit after every task with a conventional-commit message.

## Review Focus

- Email case and whitespace: `" Ana@X.com "` must register as `ana@x.com`, log in with any casing, and block a second account that differs only by case. (Task 8 test `TestRegisterNormalizesEmailAndRejectsCaseDuplicate`.)
- Passwords over 72 bytes (bcrypt's limit) must be rejected as `too_long` at registration and treated as wrong credentials at login — never a 500. (Task 3 `TestCheckPassword`, Task 8 `TestLoginRejectsOverlongPassword`.)
- Open redirect through `?next=`: `//evil.com`, `https://evil.com` and `/\evil.com` must fall back to `/account`. (Task 14 `TestLoginNextIsSanitized`.)
- A stale, expired or garbage session cookie must behave as "logged out", clear the cookie, and never 500. (Task 14 `TestGarbageSessionCookieIsCleared`.)
- `--content-dir` overriding one file (or adding a mission file) must merge with the embedded pack; a broken override or a missing directory must produce a precise error, not a panic. (Task 11 `TestOverlay*` tests, Task 12 `TestContentCheckReportsOverrideProblem`.)

Decisions made while planning (flag in review if you disagree):
1. Minigames keep their legacy paths under `content/minigames/` (e.g. `test/mercado.html`) instead of `<name>/index.html`; missions reference that path. Relative asset links inside minigames are fixed in milestone 4.
2. The converter drops three legacy "next mission" links that point at missions that never existed (`eduardo#2`, `franco#1`, `libro#2`); the old game ignored them silently.
3. CSRF protection uses Go's `http.CrossOriginProtection` (Sec-Fetch-Site/Origin based) instead of per-form tokens, so there is no `session.secret` setting.
4. Street address fields from the legacy User are dropped (country/province/city kept).
5. `Makefile` instead of `justfile` (`just` is not installed; make is everywhere).
6. The HTTP adapter package is `internal/adapters/httpserver` (a package named `http` would shadow `net/http`).
7. Content hot-reload (`--dev` watcher) moves to milestone 3, where the game manifest first consumes content; nothing reads catalogs at runtime in milestone 1.
8. Character spritesheet generation (legacy `crearSprites`) moves to milestone 3; the raw frames are moved as-is.

```go
// Command clasav runs the Clases y Aventuras server and its admin subcommands.
package main

import (
	"context"
	"fmt"
	"io"
	"os"
	"os/signal"
	"strings"
	"syscall"
)

// version is overridden at build time with -ldflags "-X main.version=...".
var version = "dev"

const usage = `usage: clasav [command] [flags]

commands:
  serve                    run the server (default)
  migrate up|down|status   manage the database schema
  content check            validate the content pack
  user create-admin        create or promote a site admin (password read from stdin)
  version                  print the version
  help                     show this help

Run "clasav <command> --help" for the flags of a command.
`

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	code := run(ctx, os.Args[1:], os.Stdin, os.Stdout, os.Stderr, os.Environ())
	stop()
	os.Exit(code)
}

// run dispatches to a subcommand and returns the process exit code.
// It never calls os.Exit so tests can drive it directly.
func run(ctx context.Context, args []string, stdin io.Reader, stdout, stderr io.Writer, environ []string) int {
	cmd := "serve"
	if len(args) > 0 && !strings.HasPrefix(args[0], "-") {
		cmd, args = args[0], args[1:]
	}
	switch cmd {
	case "version":
		fmt.Fprintf(stdout, "clasav %s\n", version)
		return 0
	case "help":
		fmt.Fprint(stdout, usage)
		return 0
	default:
		fmt.Fprintf(stderr, "unknown command %q\n\n%s", cmd, usage)
		return 2
	}
}
```

```go
		{"sqlite://clasav.db", "sqlite", "clasav.db"},
		{"sqlite:///data/clasav.db", "sqlite", "/data/clasav.db"},
		{"sqlite://:memory:", "sqlite", ":memory:"},

		{"postgresql://u@h/db?sslmode=disable", "postgres", "postgresql://u@h/db?sslmode=disable"},
```

```go
	}

// Load builds the configuration: defaults < YAML file < CLASAV_* env < flags that
// were set explicitly. fs must already be parsed.
func Load(fs *pflag.FlagSet, environ []string) (Config, error) {
	k := koanf.New(".")
	if err := k.Load(structs.Provider(Defaults(), "koanf"), nil); err != nil {
		return Config{}, fmt.Errorf("config defaults: %w", err)
	}
	known := k.Keys()

	path, explicit := configPath(fs, environ)
	if _, err := os.Stat(path); err == nil {
		if err := k.Load(file.Provider(path), yaml.Parser()); err != nil {
			return Config{}, fmt.Errorf("config file %s: %w", path, err)
		}
	} else if explicit {
		return Config{}, fmt.Errorf("config file %s: %w", path, err)
	}

	envProvider := env.Provider(".", env.Opt{
		Prefix:      envPrefix,
		EnvironFunc: func() []string { return environ },
		TransformFunc: func(key, value string) (string, any) {
			key = strings.ToLower(strings.TrimPrefix(key, envPrefix))
			if key == "config" {
				return "", nil
			}
			return strings.ReplaceAll(key, "__", "."), value
		},
	})
	if err := k.Load(envProvider, nil); err != nil {
		return Config{}, fmt.Errorf("config env: %w", err)
	}

	changed := map[string]any{}
	fs.Visit(func(f *pflag.Flag) {
		if key, ok := flagKeys[f.Name]; ok {
			changed[key] = f.Value.String()
		}
	})
	if err := k.Load(confmap.Provider(changed, "."), nil); err != nil {
		return Config{}, fmt.Errorf("config flags: %w", err)
	}

	var unknown []string
	for _, key := range k.Keys() {
		if !slices.Contains(known, key) {
			unknown = append(unknown, key)
		}
	}
	if len(unknown) > 0 {
		return Config{}, fmt.Errorf("unknown config keys: %s", strings.Join(unknown, ", "))
	}

	var cfg Config
	if err := k.Unmarshal("", &cfg); err != nil {
		return Config{}, fmt.Errorf("decode config: %w", err)
	}
	return cfg, cfg.Validate()
}

// configPath returns the config file to read and whether it was requested explicitly.
func configPath(fs *pflag.FlagSet, environ []string) (string, bool) {
	if f := fs.Lookup("config"); f != nil && f.Changed {
		return f.Value.String(), true
	}
	for _, kv := range environ {
		if v, ok := strings.CutPrefix(kv, envPrefix+"CONFIG="); ok && v != "" {
			return v, true
		}
	}
	return defaultConfigFile, false
}

func (c Config) Validate() error {
	var errs []error
	if c.Addr == "" {
		errs = append(errs, errors.New("addr must not be empty"))
	}
	if u, err := url.Parse(c.BaseURL); err != nil || (u.Scheme != "http" && u.Scheme != "https") || u.Host == "" {
		errs = append(errs, fmt.Errorf("base_url %q must be an absolute http(s) URL", c.BaseURL))
	}
	switch c.LogLevel {
	case "debug", "info", "warn", "error":
	default:
		errs = append(errs, fmt.Errorf("log_level %q must be debug, info, warn or error", c.LogLevel))
	}
	if _, _, err := SplitDSN(c.DB.DSN); err != nil {
		errs = append(errs, err)
	}
	switch c.DB.Migrate {
	case "auto", "off":
	default:
		errs = append(errs, fmt.Errorf("db.migrate %q must be auto or off", c.DB.Migrate))
	}
	if c.Session.TTL < time.Hour {
		errs = append(errs, fmt.Errorf("session.ttl %s must be at least 1h", c.Session.TTL))
	}
	return errors.Join(errs...)
}

// CookieSecure reports whether cookies must carry the Secure attribute.
func (c Config) CookieSecure() bool {
	return strings.HasPrefix(c.BaseURL, "https://")
}

// SplitDSN returns the storage driver ("sqlite" or "postgres") and the
// driver-specific connection string.
func SplitDSN(dsn string) (driver, rest string, err error) {
	switch {
	case strings.HasPrefix(dsn, "sqlite://"):
		rest = strings.TrimPrefix(dsn, "sqlite://")
		if rest == "" {
			return "", "", fmt.Errorf("db.dsn %q: missing sqlite path", dsn)
		}
		return "sqlite", rest, nil
	case strings.HasPrefix(dsn, "postgres://"), strings.HasPrefix(dsn, "postgresql://"):
		return "postgres", dsn, nil
	default:
		return "", "", fmt.Errorf("db.dsn %q: scheme must be sqlite:// or postgres://", dsn)
	}
}
```

```go
package domain

import (
	"errors"
	"maps"
	"slices"
	"strings"
)

var (
	ErrNotFound        = errors.New("not found")
	ErrConflict        = errors.New("conflict")
	ErrForbidden       = errors.New("forbidden")
	ErrUnauthenticated = errors.New("unauthenticated")
	ErrConditionNotMet = errors.New("condition not met")
	ErrValidation      = errors.New("validation failed")
)

// Validation message codes. The UI translates them; the domain never renders text.
const (
	CodeRequired = "required"
	CodeInvalid  = "invalid"
	CodeTooShort = "too_short"
	CodeTooLong  = "too_long"
	CodeTaken    = "taken"
	CodeMismatch = "mismatch"
	CodeWrong    = "wrong"
)

// ValidationError maps field names to message codes. errors.Is(err, ErrValidation) holds.
type ValidationError struct {
	Fields map[string]string
}

// Add records code for field unless the field already has one.
func (e *ValidationError) Add(field, code string) {
	if e.Fields == nil {
		e.Fields = map[string]string{}
	}
	if _, ok := e.Fields[field]; !ok {
		e.Fields[field] = code
	}
}

// OrNil returns e as an error when it holds any field, and nil otherwise.
func (e *ValidationError) OrNil() error {
	if len(e.Fields) == 0 {
		return nil
	}
	return e
}

func (e *ValidationError) Error() string {
	parts := make([]string, 0, len(e.Fields))
	for _, f := range slices.Sorted(maps.Keys(e.Fields)) {
		parts = append(parts, f+": "+e.Fields[f])
	}
	return "validation failed (" + strings.Join(parts, ", ") + ")"
}

func (e *ValidationError) Is(target error) bool { return target == ErrValidation }
```

```go
	GenderMale   Gender = "male"
	GenderFemale Gender = "female"
)

	switch g {
	case GenderUnset, GenderMale, GenderFemale:
		return true
	}
	return false
}

type Profile struct {
	FirstName string
	LastName  string
	Gender    Gender
	BirthDate *time.Time // calendar date at UTC midnight
	Country   string
	Province  string
	City      string
}

type User struct {
	ID        int64
	Email     string // always normalized
	Profile   Profile
	SiteAdmin bool
	CreatedAt time.Time
}

func NormalizeEmail(s string) string { return strings.ToLower(strings.TrimSpace(s)) }

// CheckEmail records a problem with an already normalized email address.
func CheckEmail(v *ValidationError, field, email string) {
	switch {
	case email == "":
		v.Add(field, CodeRequired)
	case len(email) > maxEmailLen:
		v.Add(field, CodeTooLong)
	default:
		a, err := mail.ParseAddress(email)
		if err != nil || a.Address != email || a.Name != "" {
			v.Add(field, CodeInvalid)
		}
	}
}

func CheckPassword(v *ValidationError, field, pw string) {
	switch {
	case pw == "":
		v.Add(field, CodeRequired)
	case utf8.RuneCountInString(pw) < MinPasswordLen:
		v.Add(field, CodeTooShort)
	case len(pw) > MaxPasswordBytes:
		v.Add(field, CodeTooLong)
	}
}

// Normalize trims text fields and reduces the birth date to its calendar date at UTC midnight.
func (p Profile) Normalize() Profile {
	p.FirstName = strings.TrimSpace(p.FirstName)
	p.LastName = strings.TrimSpace(p.LastName)
	p.Country = strings.TrimSpace(p.Country)
	p.Province = strings.TrimSpace(p.Province)
	p.City = strings.TrimSpace(p.City)
	if p.BirthDate != nil {
		y, m, d := p.BirthDate.Date()
		bd := time.Date(y, m, d, 0, 0, 0, 0, time.UTC)
		p.BirthDate = &bd
	}
	return p
}

// Check records problems with a normalized profile; now bounds the birth date.
func (p Profile) Check(v *ValidationError, now time.Time) {
	for _, f := range []struct{ name, value string }{
		{"first_name", p.FirstName}, {"last_name", p.LastName},
		{"country", p.Country}, {"province", p.Province}, {"city", p.City},
	} {
		if utf8.RuneCountInString(f.value) > maxProfileField {
			v.Add(f.name, CodeTooLong)
		}
	}
	if !p.Gender.Valid() {
		v.Add("gender", CodeInvalid)
	}
	if p.BirthDate != nil && (p.BirthDate.After(now) || p.BirthDate.Year() < 1900) {
		v.Add("birth_date", CodeInvalid)
	}
```

```go
// Package memory is an in-memory ports.Store used by tests. It is the reference
// implementation of the repository contract.
package memory

import (
	"bytes"
	"context"
	"sync"
	"time"

	"github.com/rmarku/clasav/internal/domain"
	"github.com/rmarku/clasav/internal/ports"
)

type state struct {
	nextUserID  int64
	users       map[int64]domain.User
	localHashes map[int64][]byte
	sessions    map[string]domain.Session
}

func newState() *state {
	return &state{users: map[int64]domain.User{}, localHashes: map[int64][]byte{}, sessions: map[string]domain.Session{}}
}

func copyUser(u domain.User) domain.User {
	if u.Profile.BirthDate != nil {
		bd := *u.Profile.BirthDate
		u.Profile.BirthDate = &bd
	}
	return u
}

func (s *state) clone() *state {
	c := newState()
	c.nextUserID = s.nextUserID
	for k, v := range s.users {
		c.users[k] = copyUser(v)
	}
	for k, v := range s.localHashes {
		c.localHashes[k] = bytes.Clone(v)
	}
	for k, v := range s.sessions {
		c.sessions[k] = v
	}
	return c
}

// runner executes f against the state, either under the store lock or inside a transaction.
type runner func(f func(*state) error) error

type Store struct {
	mu sync.Mutex
	st *state
}

func New() *Store { return &Store{st: newState()} }

func (s *Store) locked(f func(*state) error) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	return f(s.st)
}

func (s *Store) Users() ports.Users             { return users{s.locked} }
func (s *Store) Credentials() ports.Credentials { return credentials{s.locked} }
func (s *Store) Sessions() ports.Sessions       { return sessions{s.locked} }
func (s *Store) Ping(context.Context) error     { return nil }
func (s *Store) Close() error                   { return nil }

// WithinTx works on a copy of the state and publishes it only if fn succeeds.
func (s *Store) WithinTx(_ context.Context, fn func(ports.Repos) error) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	work := s.st.clone()
	direct := func(f func(*state) error) error { return f(work) }
	if err := fn(repos{direct}); err != nil {
		return err
	}
	s.st = work
	return nil
}

type repos struct{ run runner }

func (r repos) Users() ports.Users             { return users(r) }
func (r repos) Credentials() ports.Credentials { return credentials(r) }
func (r repos) Sessions() ports.Sessions       { return sessions(r) }

type users struct{ run runner }

func (u users) Create(_ context.Context, in domain.User) (out domain.User, err error) {
	err = u.run(func(st *state) error {
		for _, x := range st.users {
			if x.Email == in.Email {
				return domain.ErrConflict
			}
		}
		st.nextUserID++
		in.ID = st.nextUserID
		st.users[in.ID] = copyUser(in)
		out = copyUser(in)
		return nil
	})
	return out, err
}

func (u users) ByID(_ context.Context, id int64) (out domain.User, err error) {
	err = u.run(func(st *state) error {
		x, ok := st.users[id]
		if !ok {
			return domain.ErrNotFound
		}
		out = copyUser(x)
		return nil
	})
	return out, err
}

func (u users) ByEmail(_ context.Context, email string) (out domain.User, err error) {
	err = u.run(func(st *state) error {
		for _, x := range st.users {
			if x.Email == email {
				out = copyUser(x)
				return nil
			}
		}
		return domain.ErrNotFound
	})
	return out, err
}

func (u users) update(id int64, f func(*domain.User)) error {
	return u.run(func(st *state) error {
		x, ok := st.users[id]
		if !ok {
			return domain.ErrNotFound
		}
		f(&x)
		st.users[id] = copyUser(x)
		return nil
	})
}

func (u users) UpdateProfile(_ context.Context, id int64, p domain.Profile) error {
	return u.update(id, func(x *domain.User) { x.Profile = p })
}

func (u users) SetSiteAdmin(_ context.Context, id int64, admin bool) error {
	return u.update(id, func(x *domain.User) { x.SiteAdmin = admin })
}

type credentials struct{ run runner }

func (c credentials) SetLocal(_ context.Context, userID int64, hash []byte, _ time.Time) error {
	return c.run(func(st *state) error {
		if _, ok := st.users[userID]; !ok {
			return domain.ErrNotFound
		}
		st.localHashes[userID] = bytes.Clone(hash)
		return nil
	})
}

func (c credentials) LocalHash(_ context.Context, userID int64) (out []byte, err error) {
	err = c.run(func(st *state) error {
		h, ok := st.localHashes[userID]
		if !ok {
			return domain.ErrNotFound
		}
		out = bytes.Clone(h)
		return nil
	})
	return out, err
}

type sessions struct{ run runner }

func (s sessions) Create(_ context.Context, in domain.Session) error {
	return s.run(func(st *state) error {
		if _, ok := st.users[in.UserID]; !ok {
			return domain.ErrNotFound
		}
		if _, ok := st.sessions[in.TokenHash]; ok {
			return domain.ErrConflict
		}
		st.sessions[in.TokenHash] = in
		return nil
	})
}

func (s sessions) ByTokenHash(_ context.Context, h string) (out domain.Session, err error) {
	err = s.run(func(st *state) error {
		x, ok := st.sessions[h]
		if !ok {
			return domain.ErrNotFound
		}
		out = x
		return nil
	})
	return out, err
}

func (s sessions) Touch(_ context.Context, h string, expiresAt time.Time) error {
	return s.run(func(st *state) error {
		x, ok := st.sessions[h]
		if !ok {
			return domain.ErrNotFound
		}
		x.ExpiresAt = expiresAt
		st.sessions[h] = x
		return nil
	})
}

func (s sessions) Delete(_ context.Context, h string) error {
	return s.run(func(st *state) error {
		delete(st.sessions, h)
		return nil
	})
}

func (s sessions) DeleteByUser(_ context.Context, userID int64) error {
	return s.run(func(st *state) error {
		for h, x := range st.sessions {
			if x.UserID == userID {
				delete(st.sessions, h)
			}
		}
		return nil
	})
}

func (s sessions) DeleteExpired(_ context.Context, now time.Time) (n int64, err error) {
	err = s.run(func(st *state) error {
		for h, x := range st.sessions {
			if x.Expired(now) {
				delete(st.sessions, h)
				n++
			}
		}
		return nil
	})
	return n, err
}
```

```go
// Package migrate wraps goose's Provider API for the SQL adapters.
package migrate

import (
	"context"
	"database/sql"
	"fmt"
	"io"
	"io/fs"
	"path"

	"github.com/pressly/goose/v3"
)

type Migrator struct {
	p *goose.Provider
}

func New(dialect goose.Dialect, db *sql.DB, fsys fs.FS) (*Migrator, error) {
	p, err := goose.NewProvider(dialect, db, fsys)
	if err != nil {
		return nil, fmt.Errorf("migrations: %w", err)
	}
	return &Migrator{p: p}, nil
}

func (m *Migrator) Up(ctx context.Context) error {
	_, err := m.p.Up(ctx)
	return err
}

// Down rolls back the most recent migration.
func (m *Migrator) Down(ctx context.Context) error {
	_, err := m.p.Down(ctx)
	return err
}

// Version returns the applied schema version (0 for an empty database).
func (m *Migrator) Version(ctx context.Context) (int64, error) {
	current, _, err := m.p.GetVersions(ctx)
	return current, err
}

// Latest returns the highest migration version shipped with the binary.
func (m *Migrator) Latest() int64 {
	sources := m.p.ListSources()
	if len(sources) == 0 {
		return 0
	}
	return sources[len(sources)-1].Version
}

func (m *Migrator) Status(ctx context.Context, w io.Writer) error {
	statuses, err := m.p.Status(ctx)
	if err != nil {
		return err
	}
	for _, s := range statuses {
		fmt.Fprintf(w, "%-8s %s\n", s.State, path.Base(s.Source.Path))
	}
	return nil
}
```

```go
//go:embed migrations/*.sql

// dbtx is satisfied by *sql.DB and *sql.Tx.
type dbtx interface {
	ExecContext(ctx context.Context, query string, args ...any) (sql.Result, error)
	QueryContext(ctx context.Context, query string, args ...any) (*sql.Rows, error)
	QueryRowContext(ctx context.Context, query string, args ...any) *sql.Row
}

type Store struct {
	db *sql.DB
}

var memSeq atomic.Int64

// Open opens (creating if needed) the database file at path.
// The path ":memory:" opens a private in-memory database.
func Open(ctx context.Context, path string) (*Store, error) {
	var dsn string
	if path == ":memory:" {
		dsn = fmt.Sprintf("file:clasav-mem-%d?mode=memory&cache=shared&_pragma=foreign_keys(1)", memSeq.Add(1))
	} else {
		dsn = "file:" + path + "?_pragma=foreign_keys(1)&_pragma=busy_timeout(5000)&_pragma=journal_mode(WAL)&_pragma=synchronous(NORMAL)"
	}
	db, err := sql.Open("sqlite", dsn)
	if err != nil {
		return nil, fmt.Errorf("open sqlite: %w", err)
	}
	// A single connection serializes writers (SQLite allows one at a time) and
	// keeps in-memory databases alive for the lifetime of the Store.
	db.SetMaxOpenConns(1)
	db.SetConnMaxLifetime(0)
	if err := db.PingContext(ctx); err != nil {
		_ = db.Close()
		return nil, fmt.Errorf("open sqlite %s: %w", path, err)
	}
	return &Store{db: db}, nil
}

func (s *Store) Migrator() (*migrate.Migrator, error) {
	sub, err := fs.Sub(migrations, "migrations")
	if err != nil {
		return nil, err
	}
	return migrate.New(goose.DialectSQLite3, s.db, sub)
}

func (s *Store) Users() ports.Users             { return users{s.db} }
func (s *Store) Credentials() ports.Credentials { return credentials{s.db} }
func (s *Store) Sessions() ports.Sessions       { return sessions{s.db} }
func (s *Store) Ping(ctx context.Context) error { return s.db.PingContext(ctx) }
func (s *Store) Close() error                   { return s.db.Close() }

func (s *Store) WithinTx(ctx context.Context, fn func(ports.Repos) error) (err error) {
	tx, err := s.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("begin: %w", err)
	}
	defer func() {
		if p := recover(); p != nil {
			_ = tx.Rollback()
			panic(p)
		}
	}()
	if err := fn(repos{tx}); err != nil {
		_ = tx.Rollback()
		return err
	}
	return tx.Commit()
}

type repos struct{ q dbtx }

func (r repos) Users() ports.Users             { return users(r) }
func (r repos) Credentials() ports.Credentials { return credentials(r) }
func (r repos) Sessions() ports.Sessions       { return sessions(r) }
```

```go
import (
	"database/sql"
	"errors"
	"fmt"
	"strings"

	"modernc.org/sqlite"
	sqlite3 "modernc.org/sqlite/lib"

	"github.com/rmarku/clasav/internal/domain"
)

// mapErr translates driver errors into domain sentinels.
func mapErr(err error) error {
	if err == nil {
		return nil
	}
	if errors.Is(err, sql.ErrNoRows) {
		return domain.ErrNotFound
	}
	var se *sqlite.Error
	if errors.As(err, &se) {
		code := se.Code()
		msg := se.Error()
		switch {
		case code == sqlite3.SQLITE_CONSTRAINT_UNIQUE, code == sqlite3.SQLITE_CONSTRAINT_PRIMARYKEY,
			strings.Contains(msg, "UNIQUE constraint failed"):
			return fmt.Errorf("%w: %s", domain.ErrConflict, msg)
		case code == sqlite3.SQLITE_CONSTRAINT_FOREIGNKEY, strings.Contains(msg, "FOREIGN KEY constraint failed"):
			return fmt.Errorf("%w: %s", domain.ErrNotFound, msg)
		}
	}
	return err
}

// affected turns "0 rows changed" into domain.ErrNotFound.
func affected(res sql.Result, err error) error {
	if err != nil {
		return mapErr(err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return err
	}
	if n == 0 {
		return domain.ErrNotFound
	}
	return nil
}
```

```go
	db.SetConnMaxIdleTime(5 * time.Minute)
	if err := db.PingContext(ctx); err != nil {
		_ = db.Close()
		return nil, fmt.Errorf("open postgres: %w", err)
	}
	return &Store{db: db}, nil

func (s *Store) Migrator() (*migrate.Migrator, error) {
	sub, err := fs.Sub(migrations, "migrations")
	if err != nil {
		return nil, err
	}
	return migrate.New(goose.DialectPostgres, s.db, sub)
}

func (s *Store) Credentials() ports.Credentials { return credentials{s.db} }
func (s *Store) Sessions() ports.Sessions       { return sessions{s.db} }
func (s *Store) Ping(ctx context.Context) error { return s.db.PingContext(ctx) }
func (s *Store) Close() error                   { return s.db.Close() }

func (s *Store) WithinTx(ctx context.Context, fn func(ports.Repos) error) (err error) {
	tx, err := s.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("begin: %w", err)
	}
	defer func() {
		if p := recover(); p != nil {
			_ = tx.Rollback()
			panic(p)
		}
	}()
	if err := fn(repos{tx}); err != nil {
		_ = tx.Rollback()
		return err
	}
	return tx.Commit()
}

type repos struct{ q dbtx }

func (r repos) Users() ports.Users             { return users(r) }
func (r repos) Credentials() ports.Credentials { return credentials(r) }
func (r repos) Sessions() ports.Sessions       { return sessions(r) }

// ts normalizes a timestamp to what Postgres stores (UTC, microseconds).
func ts(t time.Time) time.Time { return t.UTC().Truncate(time.Microsecond) }
```

```go
func mapErr(err error) error {
	if err == nil {
		return nil
	}
	if errors.Is(err, sql.ErrNoRows) {
		return domain.ErrNotFound
	}
	var pgErr *pgconn.PgError
	if errors.As(err, &pgErr) {
		switch pgErr.Code {
		case pgUniqueViolation:
			return fmt.Errorf("%w: %s", domain.ErrConflict, pgErr.Message)
		case pgForeignKeyViolation:
			return fmt.Errorf("%w: %s", domain.ErrNotFound, pgErr.Message)
		}
	}
	return err
}

func affected(res sql.Result, err error) error {
	if err != nil {
		return mapErr(err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return err
	}
	if n == 0 {
		return domain.ErrNotFound
	}
	return nil
```

```go
		if err != nil {

		}
```
```go
		return &DB{Store: s, Migrator: m}, nil
	default:
```

```go
	case "down":
		err = db.Migrator.Down(ctx)
	case "status":
		err = db.Migrator.Status(ctx, stdout)
	}
	if err != nil {
		fmt.Fprintln(stderr, "migrate:", err)
		return 1
	}
```

```go
	err := bcrypt.CompareHashAndPassword(hash, []byte(password))
```

```go
// Package auth implements account registration, login and sessions.
package auth

import (
	"context"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"time"

	"github.com/rmarku/clasav/internal/domain"
	"github.com/rmarku/clasav/internal/ports"
)

type RegisterInput struct {
	Email           string
	Password        string
	PasswordConfirm string
	Profile         domain.Profile
}

type LoginResult struct {
	Token string
	User  domain.User
}

type Service struct {
	store  ports.Store
	hasher ports.PasswordHasher
	clock  ports.Clock
	tokens ports.TokenSource
	ttl    time.Duration
	dummy  []byte // compared against when the account does not exist, to equalize timing
}

func New(store ports.Store, hasher ports.PasswordHasher, clock ports.Clock, tokens ports.TokenSource, ttl time.Duration) (*Service, error) {
	dummy, err := hasher.Hash("clasav-timing-equalizer")
	if err != nil {
		return nil, fmt.Errorf("auth: %w", err)
	}
	return &Service{store: store, hasher: hasher, clock: clock, tokens: tokens, ttl: ttl, dummy: dummy}, nil
}

// HashToken returns the value stored for a session token. Raw tokens never reach the database.
func HashToken(token string) string {
	sum := sha256.Sum256([]byte(token))
	return hex.EncodeToString(sum[:])
}

func (s *Service) Register(ctx context.Context, in RegisterInput) (domain.User, error) {
	email := domain.NormalizeEmail(in.Email)
	profile := in.Profile.Normalize()
	v := &domain.ValidationError{}
	domain.CheckEmail(v, "email", email)
	domain.CheckPassword(v, "password", in.Password)
	if in.Password != in.PasswordConfirm {
		v.Add("password_confirm", domain.CodeMismatch)
	}
	profile.Check(v, s.clock.Now())
	if err := v.OrNil(); err != nil {
		return domain.User{}, err
	}
	return s.createUser(ctx, email, in.Password, profile, false)
}

func (s *Service) createUser(ctx context.Context, email, password string, profile domain.Profile, admin bool) (domain.User, error) {
	hash, err := s.hasher.Hash(password)
	if err != nil {
		return domain.User{}, fmt.Errorf("hash password: %w", err)
	}
	now := s.clock.Now()
	var user domain.User
	err = s.store.WithinTx(ctx, func(r ports.Repos) error {
		u, err := r.Users().Create(ctx, domain.User{Email: email, Profile: profile, SiteAdmin: admin, CreatedAt: now})
		if err != nil {
			return err
		}
		user = u
		return r.Credentials().SetLocal(ctx, u.ID, hash, now)
	})
	if errors.Is(err, domain.ErrConflict) {
		v := &domain.ValidationError{}
		v.Add("email", domain.CodeTaken)
		return domain.User{}, v
	}
	if err != nil {
		return domain.User{}, err
	}
	return user, nil
}

func (s *Service) Login(ctx context.Context, email, password string) (LoginResult, error) {
	if len(password) > domain.MaxPasswordBytes {
		return LoginResult{}, domain.ErrUnauthenticated
	}
	user, err := s.store.Users().ByEmail(ctx, domain.NormalizeEmail(email))
	if errors.Is(err, domain.ErrNotFound) {
		_ = s.hasher.Compare(s.dummy, password)
		return LoginResult{}, domain.ErrUnauthenticated
	}
	if err != nil {
		return LoginResult{}, err
	}
	hash, err := s.store.Credentials().LocalHash(ctx, user.ID)
	if errors.Is(err, domain.ErrNotFound) {
		_ = s.hasher.Compare(s.dummy, password)
		return LoginResult{}, domain.ErrUnauthenticated
	}
	if err != nil {
		return LoginResult{}, err
	}
	if err := s.hasher.Compare(hash, password); err != nil {
		return LoginResult{}, err
	}
	token, err := s.newSession(ctx, s.store, user.ID)
	if err != nil {
		return LoginResult{}, err
	}
	return LoginResult{Token: token, User: user}, nil
}

func (s *Service) newSession(ctx context.Context, r ports.Repos, userID int64) (string, error) {
	token, err := s.tokens.NewToken()
	if err != nil {
		return "", fmt.Errorf("new session token: %w", err)
	}
	now := s.clock.Now()
	err = r.Sessions().Create(ctx, domain.Session{
		TokenHash: HashToken(token),
		UserID:    userID,
		CreatedAt: now,
		ExpiresAt: now.Add(s.ttl),
	})
	if err != nil {
		return "", err
	}
	return token, nil
}

// Authenticate resolves a session token to its user, sliding the expiry forward
// once less than half of the lifetime remains.
func (s *Service) Authenticate(ctx context.Context, token string) (domain.User, error) {
	if token == "" {
		return domain.User{}, domain.ErrUnauthenticated
	}
	h := HashToken(token)
	sess, err := s.store.Sessions().ByTokenHash(ctx, h)
	if errors.Is(err, domain.ErrNotFound) {
		return domain.User{}, domain.ErrUnauthenticated
	}
	if err != nil {
		return domain.User{}, err
	}
	now := s.clock.Now()
	if sess.Expired(now) {
		_ = s.store.Sessions().Delete(ctx, h)
		return domain.User{}, domain.ErrUnauthenticated
	}
	if sess.ExpiresAt.Sub(now) < s.ttl/2 {
		if err := s.store.Sessions().Touch(ctx, h, now.Add(s.ttl)); err != nil && !errors.Is(err, domain.ErrNotFound) {
			return domain.User{}, err
		}
	}
	user, err := s.store.Users().ByID(ctx, sess.UserID)
	if errors.Is(err, domain.ErrNotFound) {
		return domain.User{}, domain.ErrUnauthenticated
	}
	return user, err
}

func (s *Service) Logout(ctx context.Context, token string) error {
	if token == "" {
		return nil
	}
	return s.store.Sessions().Delete(ctx, HashToken(token))
}
```

```go
	}
```

```go
	}
	return s.store.Users().ByID(ctx, userID)

// ChangePassword verifies the current password, stores the new one, signs out every
// session of the user and returns a fresh session token for the caller.
func (s *Service) ChangePassword(ctx context.Context, userID int64, current, next, confirm string) (string, error) {
	v := &domain.ValidationError{}
	hash, err := s.store.Credentials().LocalHash(ctx, userID)
	if err != nil {
		return "", err
	}
	if len(current) > domain.MaxPasswordBytes {
		v.Add("current_password", domain.CodeWrong)
	} else if err := s.hasher.Compare(hash, current); errors.Is(err, domain.ErrUnauthenticated) {
		v.Add("current_password", domain.CodeWrong)
	} else if err != nil {
		return "", err
	}
	domain.CheckPassword(v, "new_password", next)
	if next != confirm {
		v.Add("new_password_confirm", domain.CodeMismatch)
	}
	if err := v.OrNil(); err != nil {
		return "", err
	}
	newHash, err := s.hasher.Hash(next)
	if err != nil {
		return "", fmt.Errorf("hash password: %w", err)
	}
	var token string
	err = s.store.WithinTx(ctx, func(r ports.Repos) error {
		if err := r.Credentials().SetLocal(ctx, userID, newHash, s.clock.Now()); err != nil {
			return err
		}
		if err := r.Sessions().DeleteByUser(ctx, userID); err != nil {
			return err
		}
		var err error
		token, err = s.newSession(ctx, r, userID)
		return err
	})
	if err != nil {
		return "", err
	}
	return token, nil
}

// EnsureAdmin creates a site admin with these credentials, or promotes an existing
// user and resets their password. It reports whether a user was created.
func (s *Service) EnsureAdmin(ctx context.Context, email, password string) (domain.User, bool, error) {
	email = domain.NormalizeEmail(email)
	v := &domain.ValidationError{}
	domain.CheckEmail(v, "email", email)
	domain.CheckPassword(v, "password", password)
	if err := v.OrNil(); err != nil {
		return domain.User{}, false, err
	}
	existing, err := s.store.Users().ByEmail(ctx, email)
	if errors.Is(err, domain.ErrNotFound) {
		u, err := s.createUser(ctx, email, password, domain.Profile{}, true)
		return u, err == nil, err
	}
	if err != nil {
		return domain.User{}, false, err
	}
	hash, err := s.hasher.Hash(password)
	if err != nil {
		return domain.User{}, false, fmt.Errorf("hash password: %w", err)
	}
	err = s.store.WithinTx(ctx, func(r ports.Repos) error {
		if err := r.Users().SetSiteAdmin(ctx, existing.ID, true); err != nil {
			return err
		}
		return r.Credentials().SetLocal(ctx, existing.ID, hash, s.clock.Now())
	})
	if err != nil {
		return domain.User{}, false, err
	}
	existing.SiteAdmin = true
```

```go
// readPassword prompts without echo on a terminal, otherwise reads the first line of stdin.
func readPassword(stdin io.Reader, stderr io.Writer) (string, error) {
	if f, ok := stdin.(*os.File); ok && term.IsTerminal(int(f.Fd())) {
		fmt.Fprint(stderr, "Password: ")
		b, err := term.ReadPassword(int(f.Fd()))
		fmt.Fprintln(stderr)
		return string(b), err
	}
	line, err := bufio.NewReader(stdin).ReadString('\n')
	if err != nil && !errors.Is(err, io.EOF) {
		return "", err
	}
	return strings.TrimRight(line, "\r\n"), nil
}
```

```go
package domain

import (
	"cmp"
	"fmt"
	"slices"
)

// Content-relative directories referenced by catalog entries.
const (
	SpriteDir    = "sprites/"
	NPCSpriteDir = "sprites/characters/npc/"
	MinigameDir  = "minigames/"
)

// Problem is one consistency error in the content pack.
type Problem struct {
	Where string
	Msg   string
}

func (p Problem) String() string { return p.Where + ": " + p.Msg }

// FileExists reports whether a content-relative file exists.
type FileExists func(path string) bool

// Validate checks references between catalog entries and to content files.
func (c *Catalog) Validate(exists FileExists) []Problem {
	var ps []Problem
	add := func(where, format string, args ...any) {
		ps = append(ps, Problem{Where: where, Msg: fmt.Sprintf(format, args...)})
	}
	emptyKey := func(kind, key string) bool {
		if key == "" {
			add(kind, "entry with empty key")
			return true
		}
		return false
	}

	for key, it := range c.Items {
		if emptyKey("items", key) {
			continue
		}
		w := "items/" + key
		if !it.Type.Valid() {
			add(w, "unknown type %q", it.Type)
		}
		if it.Max < 1 {
			add(w, "max must be at least 1, got %d", it.Max)
		}
		if it.Energy < 0 {
			add(w, "energy must not be negative")
		}
		if _, ok := c.Sprites[it.Sprite]; !ok {
			add(w, "sprite %q not found", it.Sprite)
		}
	}

	for key, sp := range c.Sprites {
		if emptyKey("sprites", key) {
			continue
		}
		w := "sprites/" + key
		switch {
		case sp.Icon == "":
			add(w, "icon is required")
		case !exists(SpriteDir + sp.Icon):
			add(w, "icon file %s not found", SpriteDir+sp.Icon)
		}
	}

	for key, n := range c.NPCs {
		if emptyKey("npcs", key) {
			continue
		}
		w := "npcs/" + key
		if n.Width <= 0 || n.Height <= 0 {
			add(w, "width and height must be positive")
		}
		if p := NPCSpriteDir + n.Sprite + ".png"; !exists(p) {
			add(w, "sprite file %s not found", p)
		}
	}

	centrals := map[string]int{}
	for key, m := range c.Maps {
		if emptyKey("maps", key) {
			continue
		}
		w := "maps/" + key
		switch m.Kind {
		case MapCentral, MapSecondary:
		default:
			add(w, "unknown kind %q", m.Kind)
		}
		if m.Scope != MapShared && m.Scope != MapPerClass {
			add(w, "unknown scope %q", m.Scope)
		}
		if m.Group == "" {
			add(w, "group is required")
		} else if _, seen := centrals[m.Group]; !seen {
			centrals[m.Group] = 0
		}
		if m.Kind == MapCentral && m.Group != "" {
			centrals[m.Group]++
		}
		if !exists(m.File) {
			add(w, "map file %s not found", m.File)
		}
	}
	for group, n := range centrals {
		if n != 1 {
			add("maps/group "+group, "must have exactly one central map, has %d", n)
		}
	}

	for key, a := range c.Achievements {
		if emptyKey("achievements", key) {
			continue
		}
		w := "achievements/" + key
		if a.Name == "" {
			add(w, "name is required")
		}
		if _, ok := c.Maps[a.Map]; !ok {
			add(w, "map %q not found", a.Map)
		}
	}

	for key := range c.Talents {
		emptyKey("talents", key)
	}

	for ref, m := range c.Missions {
		w := "missions/" + m.Source + " " + ref.String()
		if _, ok := c.NPCs[ref.NPC]; !ok {
			add(w, "npc %q not found", ref.NPC)
		}
		if ref.Order < 0 {
			add(w, "order must not be negative")
		}
		if m.Portrait != "" && !exists(NPCSpriteDir+m.Portrait) {
			add(w, "portrait %s not found", NPCSpriteDir+m.Portrait)
		}
		cond := m.Conditions
		if cond.Level < 0 || cond.Energy < 0 || cond.Gold < 0 || cond.ItemQty < 0 {
			add(w, "conditions must not be negative")
		}
		if cond.Item != "" {
			if _, ok := c.Items[cond.Item]; !ok {
				add(w, "condition item %q not found", cond.Item)
			}
			if cond.ItemQty < 1 {
				add(w, "condition item %q needs item_qty >= 1", cond.Item)
			}
		}
		rw := m.Rewards
		if rw.Energy < 0 || rw.XP < 0 || rw.Gold < 0 || rw.ItemQty < 0 {
			add(w, "rewards must not be negative")
		}
		if rw.Item != "" {
			if _, ok := c.Items[rw.Item]; !ok {
				add(w, "reward item %q not found", rw.Item)
			}
			if rw.ItemQty < 1 {
				add(w, "reward item %q needs item_qty >= 1", rw.Item)
			}
		}
		if rw.Achievement != "" {
			if _, ok := c.Achievements[rw.Achievement]; !ok {
				add(w, "reward achievement %q not found", rw.Achievement)
			}
		}
		if m.Activity.Minigame != "" && m.Activity.Text != "" {
			add(w, "activity cannot have both minigame and text")
		}
		if mg := m.Activity.Minigame; mg != "" && !exists(MinigameDir+mg) {
			add(w, "minigame %s not found", MinigameDir+mg)
		}
		for _, n := range m.Next {
			next := MissionRef{NPC: n.NPC, Order: n.Order}
			if _, ok := c.Missions[next]; !ok {
				add(w, "next mission %s not found", next)
			}
		}
	}

	slices.SortFunc(ps, func(a, b Problem) int {
		return cmp.Or(cmp.Compare(a.Where, b.Where), cmp.Compare(a.Msg, b.Msg))
	})
	return ps
}
```

```go
// Package content loads the content pack: catalogs and missions from JSON, plus the
// files (maps, sprites, minigames) they reference.
package content

import (
	"errors"
	"fmt"
	"io/fs"
	"maps"
	"os"
	"slices"
	"strings"
)

type overlay struct {
	top  fs.FS
	base fs.FS
}

// Overlay serves files from dir when present and falls back to base.
// An empty dir returns base unchanged.
func Overlay(dir string, base fs.FS) (fs.FS, error) {
	if dir == "" {
		return base, nil
	}
	st, err := os.Stat(dir)
	if err != nil {
		return nil, fmt.Errorf("content dir: %w", err)
	}
	if !st.IsDir() {
		return nil, fmt.Errorf("content dir %s: not a directory", dir)
	}
	return overlay{top: os.DirFS(dir), base: base}, nil
}

func (o overlay) Open(name string) (fs.File, error) {
	f, err := o.top.Open(name)
	if err == nil {
		return f, nil
	}
	if !errors.Is(err, fs.ErrNotExist) {
		return nil, err
	}
	return o.base.Open(name)
}

// ReadDir merges both listings; entries from the directory win.
func (o overlay) ReadDir(name string) ([]fs.DirEntry, error) {
	top, topErr := fs.ReadDir(o.top, name)
	if topErr != nil && !errors.Is(topErr, fs.ErrNotExist) {
		return nil, topErr
	}
	base, baseErr := fs.ReadDir(o.base, name)
	if baseErr != nil && !errors.Is(baseErr, fs.ErrNotExist) {
		return nil, baseErr
	}
	if topErr != nil && baseErr != nil {
		return nil, baseErr
	}
	merged := map[string]fs.DirEntry{}
	for _, e := range base {
		merged[e.Name()] = e
	}
	for _, e := range top {
		merged[e.Name()] = e
	}
	return slices.SortedFunc(maps.Values(merged), func(a, b fs.DirEntry) int {
		return strings.Compare(a.Name(), b.Name())
	}), nil
}
```

```go
// Load reads the pack in fsys. It returns an error when a required file is
// missing or malformed; duplicate keys and validation findings are returned as problems.
func Load(fsys fs.FS) (*domain.Catalog, []domain.Problem, error) {
	c := domain.NewCatalog()
	var ps []domain.Problem
	dup := func(file, key string) {
		ps = append(ps, domain.Problem{Where: file, Msg: fmt.Sprintf("duplicate key %q", key)})
	}

	var items []itemFile
	if err := readJSON(fsys, "catalog/items.json", &items); err != nil {
		return nil, nil, err
	}
	for _, f := range items {
		if _, ok := c.Items[f.Key]; ok {
			dup("catalog/items.json", f.Key)
			continue
		}
		c.Items[f.Key] = f.toDomain()
	}

	var sprites []spriteFile
	if err := readJSON(fsys, "catalog/sprites.json", &sprites); err != nil {
		return nil, nil, err
	}
	for _, f := range sprites {
		if _, ok := c.Sprites[f.Key]; ok {
			dup("catalog/sprites.json", f.Key)
			continue
		}
		c.Sprites[f.Key] = f.toDomain()
	}

	var npcs []npcFile
	if err := readJSON(fsys, "catalog/npcs.json", &npcs); err != nil {
		return nil, nil, err
	}
	for _, f := range npcs {
		if _, ok := c.NPCs[f.Key]; ok {
			dup("catalog/npcs.json", f.Key)
			continue
		}
		c.NPCs[f.Key] = f.toDomain()
	}

	var mf mapsFile
	if err := readJSON(fsys, "catalog/maps.json", &mf); err != nil {
		return nil, nil, err
	}
	for _, f := range mf.Templates {
		if _, ok := c.Maps[f.Key]; ok {
			dup("catalog/maps.json", f.Key)
			continue
		}
		c.Maps[f.Key] = f.toDomain()
	}

	var achievements []achievementFile
	if err := readJSON(fsys, "catalog/achievements.json", &achievements); err != nil {
		return nil, nil, err
	}
	for _, f := range achievements {
		if _, ok := c.Achievements[f.Key]; ok {
			dup("catalog/achievements.json", f.Key)
			continue
		}
		c.Achievements[f.Key] = f.toDomain()
	}

	var talents []talentFile
	if err := readJSON(fsys, "catalog/talents.json", &talents); err != nil {
		return nil, nil, err
	}
	for _, f := range talents {
		if _, ok := c.Talents[f.Key]; ok {
			dup("catalog/talents.json", f.Key)
			continue
		}
		c.Talents[f.Key] = f.toDomain()
	}

	names, err := fs.Glob(fsys, "missions/*.json")
	if err != nil {
		return nil, nil, fmt.Errorf("content: list missions: %w", err)
	}
	for _, name := range names {
		var missions []missionFile
		if err := readJSON(fsys, name, &missions); err != nil {
			return nil, nil, err
		}
		source := path.Base(name)
		for _, f := range missions {
			m := f.toDomain(source)
			if prev, ok := c.Missions[m.Ref]; ok {
				ps = append(ps, domain.Problem{
					Where: "missions/" + source + " " + m.Ref.String(),
					Msg:   "duplicate mission, first defined in missions/" + prev.Source,
				})
				continue
			}
			c.Missions[m.Ref] = m
		}
	}

	exists := func(p string) bool {
		st, err := fs.Stat(fsys, p)
		return err == nil && !st.IsDir()
	}
	ps = append(ps, c.Validate(exists)...)
	slices.SortFunc(ps, func(a, b domain.Problem) int {
		return cmp.Or(cmp.Compare(a.Where, b.Where), cmp.Compare(a.Msg, b.Msg))
	})
	return c, ps, nil
}

func readJSON(fsys fs.FS, name string, v any) error {
	f, err := fsys.Open(name)
	if err != nil {
		return fmt.Errorf("content: %w", err)
	}
	defer f.Close()
	dec := json.NewDecoder(f)
	dec.DisallowUnknownFields()
	if err := dec.Decode(v); err != nil {
		return fmt.Errorf("content: %s: %w", name, err)
	}
	return nil
}
```

```go
// Source is a validated content pack. It implements ports.Catalog.
type Source struct {

// NewSource loads fsys and refuses packs with problems.
func NewSource(fsys fs.FS) (*Source, error) {
	cat, ps, err := Load(fsys)
	if err != nil {
		return nil, err
	}
	if len(ps) > 0 {
		return nil, &ProblemsError{Problems: ps}
	}
	return &Source{fsys: fsys, cat: cat}, nil
}

func (s *Source) Catalog() *domain.Catalog { return s.cat }

// FS is the content filesystem (embedded pack plus overrides), served under /content/.
func (s *Source) FS() fs.FS { return s.fsys }

type ProblemsError struct {
	Problems []domain.Problem
}

func (e *ProblemsError) Error() string {
	lines := make([]string, len(e.Problems))
	for i, p := range e.Problems {
		lines[i] = "  " + p.String()
	}
	return fmt.Sprintf("content pack has %d problem(s):\n%s", len(e.Problems), strings.Join(lines, "\n"))
}
```

```go
var accents = strings.NewReplacer(
	"á", "a", "é", "e", "í", "i", "ó", "o", "ú", "u", "ü", "u", "ñ", "n",
	"Á", "a", "É", "e", "Í", "i", "Ó", "o", "Ú", "u", "Ü", "u", "Ñ", "n",
)

func slug(s string) string {
	s = strings.ToLower(accents.Replace(s))
	var b strings.Builder
	dash := false
	for _, r := range s {
		if (r >= 'a' && r <= 'z') || (r >= '0' && r <= '9') {
			b.WriteRune(r)
			dash = false
		} else if !dash && b.Len() > 0 {
			b.WriteByte('-')
			dash = true
		}
	}
	return strings.TrimSuffix(b.String(), "-")
}

type converter struct {
	in   string
	errs []string
}

func (c *converter) fail(format string, args ...any) {
	c.errs = append(c.errs, fmt.Sprintf(format, args...))
}

func (c *converter) read(name string) []record {
	b, err := os.ReadFile(filepath.Join(c.in, name))
	if err != nil {
		c.fail("%v", err)
		return nil
	}
	var rs []record
	if err := json.Unmarshal(b, &rs); err != nil {
		c.fail("%s: %v", name, err)
	}
	return rs
}

func str(r record, k string) string {
	switch v := r[k].(type) {
	case nil:
		return ""
	case string:
		return v
	case float64:
		return strconv.FormatFloat(v, 'f', -1, 64)
	default:
		return fmt.Sprint(v)
	}
}

func (c *converter) num(r record, k, where string) int {
	s := strings.TrimSpace(str(r, k))
	if s == "" {
		return 0
	}
	n, err := strconv.Atoi(s)
	if err != nil {
		c.fail("%s: %s=%q is not an integer", where, k, s)
	}
	return n
}

func boolean(r record, k string) bool {
	switch v := r[k].(type) {
	case bool:
		return v
	case string:
		return strings.EqualFold(strings.TrimSpace(v), "true")
	}
	return false
}

func convert(in, out string, log io.Writer) error {
	c := &converter{in: in}

	spriteKeys := map[int]string{} // legacy 1-based id -> key
	var sprites []sprite
	seen := map[string]int{}
	for i, r := range c.read("Sprite.json") {
		icon := str(r, "icono")
		base := strings.TrimSuffix(strings.TrimPrefix(icon, "items/"), path.Ext(icon))
		seen[base]++
		key := base
		if seen[base] > 1 {
			key = fmt.Sprintf("%s-%d", base, seen[base])
		}
		spriteKeys[i+1] = key
		sprites = append(sprites, sprite{
			Key: key, Image: str(r, "imagen"), Icon: icon,
			XOffset: c.num(r, "xoffset", key), YOffset: c.num(r, "yoffset", key), ZIndex: c.num(r, "zIndex", key),
		})
	}

	itemKeys := map[string]bool{}
	var items []item
	for _, r := range c.read("Item.json") {
		name := str(r, "nombre")
		key := slug(name)
		typ, ok := itemTypes[str(r, "tipo_item")]
		if !ok {
			c.fail("item %s: unknown tipo_item %q", name, str(r, "tipo_item"))
		}
		sk, ok := spriteKeys[c.num(r, "sprite", key)]
		if !ok {
			c.fail("item %s: sprite %s not found", name, str(r, "sprite"))
		}
		if itemKeys[key] {
			c.fail("item key %q is not unique", key)
		}
		itemKeys[key] = true
		items = append(items, item{
			Key: key, Name: name, Type: typ, Max: c.num(r, "maximo", key),
			Sprite: sk, Color: str(r, "color"), Energy: c.num(r, "energia", key),
		})
	}
	itemRef := func(name, where string) string {
		if name == "" {
			return ""
		}
		key := slug(name)
		if !itemKeys[key] {
			c.fail("%s: item %q not found", where, name)
		}
		return key
	}

	var npcs []npc
	for _, r := range c.read("Npcplayer.json") {
		name := str(r, "nombre")
		key := strings.ToLower(name)
		npcs = append(npcs, npc{
			Key: key, Name: name, Sprite: str(r, "sprite"),
			Width: c.num(r, "width", key), Height: c.num(r, "height", key), Animation: c.num(r, "animation", key),
		})

	groupCentral := map[string]string{} // dependency id ("" = shared) -> central map

		if str(r, "tipo") != "central" {
			continue
		}
		dep := str(r, "dependencia_mapa_generico")
		if prev, dup := groupCentral[dep]; dup {
			c.fail("maps %s and %s are both central in group %q", prev, str(r, "nombre"), dep)
		}
		groupCentral[dep] = str(r, "nombre")
	}
	mapNames := map[int]string{}
	var templates []mapTemplate
	for i, r := range legacyMaps {
		name := str(r, "nombre")
		dep := str(r, "dependencia_mapa_generico")
		mapNames[i+1] = name
		kind, scope := "secondary", "class"
		if str(r, "tipo") == "central" {
			kind = "central"
		}
		if dep == "" {
			scope = "shared"
		}
		group, ok := groupCentral[dep]
		if !ok {
			c.fail("map %s: group %q has no central map", name, dep)
		}
		templates = append(templates, mapTemplate{Key: name, Kind: kind, Scope: scope, Group: group, File: "maps/" + name + ".tmx"})
	}

	achievementKeys := map[int]string{}
	var achievements []achievement
	for i, r := range c.read("Logro.json") {
		name := str(r, "nombre")
		key := slug(name)
		m, ok := mapNames[c.num(r, "mapa_generico", key)]
		if !ok {
			c.fail("achievement %s: map %s not found", name, str(r, "mapa_generico"))
		}
		achievementKeys[i+1] = key

					Item: itemRef(str(r, "cond_item"), where), ItemQty: c.num(r, "cond_item_cant", where),

			var kept []next

				ref := fmt.Sprintf("%s#%d", n.NPC, n.Order)
				if defined[ref] {
					kept = append(kept, n)
					continue
				}
				fmt.Fprintf(log, "dropped dangling next mission %s from %s %s#%d\n", ref, files[fi].name, m.NPC, m.Order)
			}
			m.Next = kept
```

```go
// Package httpserver is the HTTP driving adapter: portal pages, static files and
// health endpoints.
package httpserver

import (
	"context"
	"io"
	"io/fs"
	"log/slog"
	"net/http"

	"github.com/rmarku/clasav/web/portal"
)

type Deps struct {
	Logger  *slog.Logger
	Content fs.FS                           // served under /content/
	Ready   func(ctx context.Context) error // nil means always ready
}

type Server struct {
	d   Deps
	mux *http.ServeMux
}

func New(d Deps) http.Handler {
	if d.Logger == nil {
		d.Logger = slog.New(slog.DiscardHandler)
	}
	s := &Server{d: d, mux: http.NewServeMux()}
	s.routes()
	var h http.Handler = s.mux
	h = http.NewCrossOriginProtection().Handler(h)
	h = securityHeaders(h)
	h = s.recoverPanics(h)
	h = s.logRequests(h)
	return requestID(h)
}

func (s *Server) routes() {
	s.mux.HandleFunc("GET /healthz", func(w http.ResponseWriter, _ *http.Request) {
		_, _ = io.WriteString(w, "ok\n")
```

```go
package httpserver

import (
	"io"
	"io/fs"
	"net/http"
	"path"
	"strconv"
	"strings"
)

// fileServer serves regular files from fsys. Directories and missing files are 404;
// unlike http.FileServer it never lists directories or redirects index.html.
func fileServer(fsys fs.FS) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		name := strings.TrimPrefix(path.Clean("/"+r.URL.Path), "/")
		if name == "" {
			http.NotFound(w, r)
			return
		}
		f, err := fsys.Open(name)
		if err != nil {
			http.NotFound(w, r)
			return
		}
		defer f.Close()
		st, err := f.Stat()
		if err != nil || st.IsDir() {
			http.NotFound(w, r)
			return
		}
		rs, ok := f.(io.ReadSeeker)
		if !ok {
			http.Error(w, "file not seekable", http.StatusInternalServerError)
			return
		}
		http.ServeContent(w, r, st.Name(), st.ModTime(), rs)
	})
}

func cacheFor(seconds int, next http.Handler) http.Handler {
	value := "public, max-age=" + strconv.Itoa(seconds)
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Cache-Control", value)
		next.ServeHTTP(w, r)
	})
}
```

```go
package httpserver

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"errors"
	"fmt"
	"log/slog"
	"net/http"
	"time"
)

type ctxKey int

const requestIDKey ctxKey = 0

func requestID(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		id := r.Header.Get("X-Request-ID")
		if id == "" || len(id) > 64 {
			b := make([]byte, 8)
			_, _ = rand.Read(b)
			id = hex.EncodeToString(b)
		}
		w.Header().Set("X-Request-ID", id)
		next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), requestIDKey, id)))
	})
}

func reqID(r *http.Request) string {
	id, _ := r.Context().Value(requestIDKey).(string)
	return id
}

type statusRecorder struct {
	http.ResponseWriter
	status int
}

func (s *statusRecorder) WriteHeader(code int) {
	if s.status == 0 {
		s.status = code
	}
	s.ResponseWriter.WriteHeader(code)
}

func (s *statusRecorder) Write(b []byte) (int, error) {
	if s.status == 0 {
		s.status = http.StatusOK
	}
	return s.ResponseWriter.Write(b)
}

func (s *statusRecorder) Unwrap() http.ResponseWriter { return s.ResponseWriter }

func (s *Server) logRequests(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		rec := &statusRecorder{ResponseWriter: w}
		next.ServeHTTP(rec, r)
		if rec.status == 0 {
			rec.status = http.StatusOK
		}
		s.d.Logger.LogAttrs(r.Context(), slog.LevelInfo, "http",
			slog.String("method", r.Method),
			slog.String("path", r.URL.Path),
			slog.Int("status", rec.status),
			slog.Duration("duration", time.Since(start)),
			slog.String("request_id", reqID(r)),
		)
	})
}

func (s *Server) recoverPanics(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if p := recover(); p != nil {
				if err, ok := p.(error); ok && errors.Is(err, http.ErrAbortHandler) {
					panic(p)
				}
				s.serverError(w, r, fmt.Errorf("panic: %v", p))
			}
		}()
		next.ServeHTTP(w, r)
	})
}

func securityHeaders(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		h := w.Header()
		h.Set("X-Content-Type-Options", "nosniff")
		h.Set("Referrer-Policy", "same-origin")
		h.Set("X-Frame-Options", "SAMEORIGIN") // minigames are same-origin iframes
		next.ServeHTTP(w, r)
	})
}
```

```go
func isHTMX(r *http.Request) bool { return r.Header.Get("HX-Request") == "true" }

func (s *Server) render(w http.ResponseWriter, r *http.Request, status int, c templ.Component) {
	w.Header().Set("Content-Type", "text/html; charset=utf-8")
	w.WriteHeader(status)
	if err := c.Render(r.Context(), w); err != nil {
		s.d.Logger.ErrorContext(r.Context(), "render failed", "err", err, "request_id", reqID(r))
	}
}

// page renders the full page for normal requests and only the fragment for htmx.
func (s *Server) page(w http.ResponseWriter, r *http.Request, status int, full, fragment templ.Component) {
	if isHTMX(r) {
		s.render(w, r, status, fragment)
		return
	}
	s.render(w, r, status, full)
}

// redirect uses HX-Redirect for htmx requests (a 3xx would be followed inside the swap).
func (s *Server) redirect(w http.ResponseWriter, r *http.Request, target string) {
	if isHTMX(r) {
		w.Header().Set("HX-Redirect", target)
		w.WriteHeader(http.StatusOK)
		return
	}
	http.Redirect(w, r, target, http.StatusSeeOther)
}

func (s *Server) serverError(w http.ResponseWriter, r *http.Request, err error) {
	s.d.Logger.ErrorContext(r.Context(), "request failed", "err", err, "request_id", reqID(r))
	s.render(w, r, http.StatusInternalServerError, views.ErrorPage(http.StatusInternalServerError, reqID(r)))
}

func (s *Server) notFound(w http.ResponseWriter, r *http.Request) {
	s.render(w, r, http.StatusNotFound, views.ErrorPage(http.StatusNotFound, reqID(r)))
}
```

```go
	"net/url"
	"strings"
	"time"

	"github.com/rmarku/clasav/internal/domain"
)

const (
	sessionCookieName        = "clasav_session"
	userKey           ctxKey = 1
)

func currentUser(r *http.Request) (domain.User, bool) {
	u, ok := r.Context().Value(userKey).(domain.User)
	return u, ok
}

// session resolves the session cookie into a user in the request context.
// Unknown or expired cookies are cleared; the request continues anonymously.
func (s *Server) session(h http.HandlerFunc) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		c, err := r.Cookie(sessionCookieName)
		if err != nil || c.Value == "" {
			h(w, r)
			return
		}
		user, err := s.d.Auth.Authenticate(r.Context(), c.Value)
		switch {
		case err == nil:
			s.setSessionCookie(w, c.Value) // sliding cookie lifetime
			r = r.WithContext(context.WithValue(r.Context(), userKey, user))
		case errors.Is(err, domain.ErrUnauthenticated):
			s.clearSessionCookie(w)
		default:
			s.serverError(w, r, err)
			return
		}
		h(w, r)
	})
}

// requireUser redirects anonymous visitors to the login page, remembering where they were going.
func (s *Server) requireUser(h http.HandlerFunc) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		if _, ok := currentUser(r); !ok {
			s.redirect(w, r, "/login?next="+url.QueryEscape(r.URL.RequestURI()))
			return
		}
		h(w, r)
	}
}

func (s *Server) setSessionCookie(w http.ResponseWriter, token string) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookieName,
		Value:    token,
		Path:     "/",
		MaxAge:   int(s.d.SessionTTL / time.Second),
		HttpOnly: true,
		Secure:   s.d.CookieSecure,
		SameSite: http.SameSiteLaxMode,
	})
}

func (s *Server) clearSessionCookie(w http.ResponseWriter) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookieName,
		Value:    "",
		Path:     "/",
		MaxAge:   -1,
		HttpOnly: true,
		Secure:   s.d.CookieSecure,
		SameSite: http.SameSiteLaxMode,
	})
}

// safeNext returns next when it is a same-site path, otherwise fallback.
func safeNext(next, fallback string) string {
	if next == "" || !strings.HasPrefix(next, "/") || strings.HasPrefix(next, "//") || strings.HasPrefix(next, "/\\") {
		return fallback
	}
	u, err := url.Parse(next)
	if err != nil || u.IsAbs() || u.Host != "" {
		return fallback
	}
	return next
}
```

```go
func (s *Server) home(w http.ResponseWriter, r *http.Request) {

		return
	}
	s.redirect(w, r, "/login")

func (s *Server) loginPage(w http.ResponseWriter, r *http.Request) {
	next := r.URL.Query().Get("next")
	if _, ok := currentUser(r); ok {
		s.redirect(w, r, safeNext(next, "/account"))
		return
	}
	s.render(w, r, http.StatusOK, views.LoginPage(views.LoginForm{Next: next}))
}

func (s *Server) login(w http.ResponseWriter, r *http.Request) {
	if err := r.ParseForm(); err != nil {
		s.badRequest(w, r)
		return
	}
	f := views.LoginForm{Email: r.PostFormValue("email"), Next: r.PostFormValue("next")}
	res, err := s.d.Auth.Login(r.Context(), f.Email, r.PostFormValue("password"))
	if errors.Is(err, domain.ErrUnauthenticated) {
		f.Failed = true
		s.page(w, r, http.StatusUnauthorized, views.LoginPage(f), views.LoginFormView(f))
		return
	}
	if err != nil {
		s.serverError(w, r, err)
		return
	}
	s.setSessionCookie(w, res.Token)
	s.redirect(w, r, safeNext(f.Next, "/account"))
}

func (s *Server) registerPage(w http.ResponseWriter, r *http.Request) {
	if _, ok := currentUser(r); ok {
		s.redirect(w, r, "/account")
		return
	}
	s.render(w, r, http.StatusOK, views.RegisterPage(views.RegisterForm{}))
}

func (s *Server) register(w http.ResponseWriter, r *http.Request) {
	if err := r.ParseForm(); err != nil {
		s.badRequest(w, r)
		return
	}
	f := views.RegisterForm{
		Email:     r.PostFormValue("email"),
		FirstName: r.PostFormValue("first_name"),
		LastName:  r.PostFormValue("last_name"),
	}
	password := r.PostFormValue("password")
	_, err := s.d.Auth.Register(r.Context(), auth.RegisterInput{
		Email:           f.Email,
		Password:        password,
		PasswordConfirm: r.PostFormValue("password_confirm"),
		Profile:         domain.Profile{FirstName: f.FirstName, LastName: f.LastName},
	})
	var ve *domain.ValidationError
	if errors.As(err, &ve) {
		f.Errors = ve.Fields
		s.page(w, r, http.StatusUnprocessableEntity, views.RegisterPage(f), views.RegisterFormView(f))
		return
	}
	if err != nil {
		s.serverError(w, r, err)
		return
	}
	res, err := s.d.Auth.Login(r.Context(), f.Email, password)
	if err != nil {
		s.serverError(w, r, err)
		return
	}
	s.setSessionCookie(w, res.Token)
	s.redirect(w, r, "/account")
}

func (s *Server) logout(w http.ResponseWriter, r *http.Request) {
	if c, err := r.Cookie(sessionCookieName); err == nil {
		if err := s.d.Auth.Logout(r.Context(), c.Value); err != nil {
			s.serverError(w, r, err)
			return
		}
	}
	s.clearSessionCookie(w)
	s.redirect(w, r, "/login")
}
```

```go
func (s *Server) account(w http.ResponseWriter, r *http.Request) {
	u, _ := currentUser(r)

	if r.URL.Query().Get("edit") == "profile" {

	s.render(w, r, http.StatusOK, views.AccountPage(u, profile, views.PasswordForm{}))

func (s *Server) profileView(w http.ResponseWriter, r *http.Request) {
	if !isHTMX(r) {
		s.redirect(w, r, "/account")
		return
	}
	u, _ := currentUser(r)
	s.render(w, r, http.StatusOK, views.ProfileView(u))
}

func (s *Server) profileEdit(w http.ResponseWriter, r *http.Request) {
	if !isHTMX(r) {
		s.redirect(w, r, "/account?edit=profile")
		return
	}
	u, _ := currentUser(r)
	s.render(w, r, http.StatusOK, views.ProfileFormView(views.ProfileFormFrom(u.Profile)))
}

func (s *Server) updateProfile(w http.ResponseWriter, r *http.Request) {
	u, _ := currentUser(r)
	if err := r.ParseForm(); err != nil {
		s.badRequest(w, r)
		return
	}
	f := views.ProfileForm{
		FirstName: r.PostFormValue("first_name"),
		LastName:  r.PostFormValue("last_name"),
		Gender:    r.PostFormValue("gender"),
		BirthDate: strings.TrimSpace(r.PostFormValue("birth_date")),
		Country:   r.PostFormValue("country"),
		Province:  r.PostFormValue("province"),
		City:      r.PostFormValue("city"),
	}
	p := domain.Profile{
		FirstName: f.FirstName, LastName: f.LastName, Gender: domain.Gender(f.Gender),
		Country: f.Country, Province: f.Province, City: f.City,
	}
	if f.BirthDate != "" {
		bd, err := time.Parse(time.DateOnly, f.BirthDate)
		if err != nil {
			f.Errors = map[string]string{"birth_date": domain.CodeInvalid}
			s.profileFormError(w, r, u, f)
			return
		}
		p.BirthDate = &bd
	}
	updated, err := s.d.Auth.UpdateProfile(r.Context(), u.ID, p)
	var ve *domain.ValidationError
	switch {
	case errors.As(err, &ve):
		f.Errors = ve.Fields
		s.profileFormError(w, r, u, f)
	case err != nil:
		s.serverError(w, r, err)
	case isHTMX(r):
		s.render(w, r, http.StatusOK, views.ProfileView(updated))
	default:
		s.redirect(w, r, "/account")
	}
}

func (s *Server) profileFormError(w http.ResponseWriter, r *http.Request, u domain.User, f views.ProfileForm) {
	s.page(w, r, http.StatusUnprocessableEntity,
		views.AccountPage(u, views.ProfileFormView(f), views.PasswordForm{}),
		views.ProfileFormView(f))
}

func (s *Server) changePassword(w http.ResponseWriter, r *http.Request) {
	u, _ := currentUser(r)
	if err := r.ParseForm(); err != nil {
		s.badRequest(w, r)
		return
	}
	token, err := s.d.Auth.ChangePassword(r.Context(), u.ID,
		r.PostFormValue("current_password"), r.PostFormValue("new_password"), r.PostFormValue("new_password_confirm"))
	var ve *domain.ValidationError
	switch {
	case errors.As(err, &ve):
		f := views.PasswordForm{Errors: ve.Fields}
		s.page(w, r, http.StatusUnprocessableEntity, views.AccountPage(u, views.ProfileView(u), f), views.PasswordFormView(f))
	case err != nil:
		s.serverError(w, r, err)
	default:
		s.setSessionCookie(w, token)
		f := views.PasswordForm{Saved: true}
		s.page(w, r, http.StatusOK, views.AccountPage(u, views.ProfileView(u), f), views.PasswordFormView(f))
	}
}
```

```go
// buildApp wires adapters into the HTTP handler. Content problems fail startup.
func buildApp(ctx context.Context, cfg config.Config, logger *slog.Logger) (*app, error) {
	fsys, err := content.Overlay(cfg.Content.Dir, contentpack.FS)
	if err != nil {
		return nil, err
	}
	src, err := content.NewSource(fsys)
	if err != nil {
		return nil, err
	}
	db, err := openDB(ctx, cfg)
	if err != nil {
		return nil, err
	}
	if cfg.DB.Migrate == "auto" {
		if err := db.Migrator.Up(ctx); err != nil {
			_ = db.Close()
			return nil, fmt.Errorf("migrate: %w", err)
		}
	}
	svc, err := newAuthService(db.Store, cfg)
	if err != nil {
		_ = db.Close()
		return nil, err
	}
	h := httpserver.New(httpserver.Deps{
		Logger:       logger,
		Auth:         svc,
		SessionTTL:   cfg.Session.TTL,
		CookieSecure: cfg.CookieSecure(),
		Content:      src.FS(),
		Ready:        db.Store.Ping,
	})
	return &app{Handler: h, auth: svc, db: db, logger: logger}, nil
}

func (a *app) Close() { _ = a.db.Close() }

// purgeSessions deletes expired sessions every interval until ctx is done.
func (a *app) purgeSessions(ctx context.Context, every time.Duration) {
	t := time.NewTicker(every)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			n, err := a.auth.PurgeExpiredSessions(ctx)
			if err != nil {
				a.logger.WarnContext(ctx, "purge sessions", "err", err)
			} else if n > 0 {
				a.logger.InfoContext(ctx, "purged expired sessions", "count", n)
			}
		}
	}
}

func newLogger(w io.Writer, cfg config.Config) *slog.Logger {
	var level slog.Level
	_ = level.UnmarshalText([]byte(cfg.LogLevel)) // validated by config
	opts := &slog.HandlerOptions{Level: level}
	if cfg.Dev {
		return slog.New(slog.NewTextHandler(w, opts))
	}
	return slog.New(slog.NewJSONHandler(w, opts))
}
```

```go
package main

import (
	"context"
	"errors"
	"io"
	"log/slog"
	"net/http"
	"time"
)

func runServe(ctx context.Context, args []string, _ io.Writer, stderr io.Writer, environ []string) int {
	cfg, err := loadConfig("serve", args, environ, stderr, nil)
	if err != nil {
		return flagError(stderr, err)
	}
	logger := newLogger(stderr, cfg)
	a, err := buildApp(ctx, cfg, logger)
	if err != nil {
		logger.Error("startup failed", "err", err)
		return 1
	}
	defer a.Close()

	srv := &http.Server{
		Addr:              cfg.Addr,
		Handler:           a.Handler,
		ReadHeaderTimeout: 10 * time.Second,
		ErrorLog:          slog.NewLogLogger(logger.Handler(), slog.LevelWarn),
	}
	go a.purgeSessions(ctx, time.Hour)

	errc := make(chan error, 1)
	go func() {
		logger.Info("listening", "addr", cfg.Addr, "base_url", cfg.BaseURL, "version", version)
		errc <- srv.ListenAndServe()
	}()

	select {
	case err := <-errc:
		if !errors.Is(err, http.ErrServerClosed) {
			logger.Error("server failed", "err", err)
			return 1
		}
		return 0
	case <-ctx.Done():
	}
	logger.Info("shutting down")
	shutdownCtx, cancel := context.WithTimeout(context.Background(), 15*time.Second)
	defer cancel()
	if err := srv.Shutdown(shutdownCtx); err != nil {
		logger.Error("shutdown failed", "err", err)
		return 1
	}
	return 0
}
```
